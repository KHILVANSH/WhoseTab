# No AI Slop Rule

All user interfaces, button labels, notifications, modals, error messages, and documentation in this workspace must adhere to clean, professional, human-designed standards:

1. **Zero Decorative Emojis**: Never use emojis (`⚡`, `🎉`, `💳`, `🥦`, `⚠️`, etc.) in buttons, headers, status messages, or banners. Use clean monochrome SVG icons or plain text.
2. **No Robotic Slop Badges**: Never inject badges like `"Auto"`, `"Custom"`, `"Smart"`, or `"Magic"`. Keep forms and calculations subtle and self-adjusting without noisy labels.
3. **No Patronizing Tips**: Do not add `"Tip: ..."` or micro-explaining banners. Make interactions discoverable through clean layouts.
4. **Natural Button Copy**: Use concise, functional verbs (e.g. `"Add Expense"`, `"Split equally"`, `"Save"`, `"Dismiss"`).
5. **Direct Diagnostics**: Error messages should clearly state what is missing without exclamation spam or cartoonish phrasing.
